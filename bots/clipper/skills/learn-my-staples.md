# Learn my staples

Use this to build or refresh `staples`, the items the user buys most. Run it during setup, then on the first Sunday of each month.

1. In each store in `stores`, open the purchase history, such as Meijer's "Purchases" or receipts, Kroger's "Purchases", or Publix's "Purchase History". Read the last 90 days. If a store has no history online, skip it.
2. Combine the items across stores. Treat the same thing from different stores, sizes, or flavors as one staple, for example "2% milk, gallon". Note which brands they buy. If they always buy one brand, a coupon for another brand is a weak match.
3. Rank by how often they buy each item. Keep the top 40 or so, plus anything bought at least twice a month.
4. The first time, show the user the list grouped by category and ask what to add, remove, or fix, such as "we switched to oat milk". Later, just tell them what changed. Save the result in `staples`.
